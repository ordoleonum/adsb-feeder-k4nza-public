Depending on the amount of historic replay / heatmap data you have, a Full Backup can take a signficant amount of time and result in a very large archive to be downloaded. If you want to limit the data retained on disk, you can use MAX_GLOBE_HISTORY=365 in the environment variables on the expert page to only retain a year of data, this setting will not impact graph data.

Network backup (NAS)

Saves a backup to a shared folder on a NAS (for example a Synology) every night: your settings and graphs and, when SkyStats is on, the SkyStats database. The feeder only connects to the NAS while the backup runs, so if the NAS is switched off the feeder keeps working normally and this page shows that the backup failed. Nothing extra is written to the SD card. Older backups are deleted automatically.
